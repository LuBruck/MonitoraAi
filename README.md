# MonitoraAí

Aplicação web para **cadastrar e consultar monitorias** da faculdade por disciplina, dia e horário.

> 🚧 Em desenvolvimento. Este README será completado ao longo do projeto.

## Problema
As informações de monitoria ficam espalhadas em murais e grupos. O MonitoraAí centraliza tudo e impede choque de horário no mesmo local.
